# Tic Tac Toe Game 🎮

A simple and interactive **Tic Tac Toe game** developed using **Java**. The game allows two players to play against each other by placing `X` and `O` on a 3×3 game board.

### Features

* 🎯 Two-player gameplay
* 🧩 3×3 interactive game board
* 🏆 Automatic winner detection
* 🤝 Draw/tie detection
* 🔄 Simple and user-friendly gameplay
* ⚡ Fast and lightweight Java application
